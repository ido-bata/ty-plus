# ADR-0007: 公式Webサイトのプラットフォーム構成

- Status: Accepted（2026-11-20 ユーザー決定）
- 正本: 本文 / Epic Issue #255 / 配下のticket Issue（#256〜#261）
- 対象: 公式Webサイトの初期版と、その後の拡張の土台

## Decision

公式Webサイトを、既存CEPアプリと一体のBun Workspacesモノレポとして `apps/web` に構築する。

| 項目 | 決定 |
| --- | --- |
| Framework | TanStack Start 1.x（React 19 / TypeScript / Vite） |
| 共有基盤 | Panda CSS / Bun / React を既存アプリと共有 |
| デザインシステム | Panda tokens・テーマ・共通Reactコンポーネントを共有パッケージへ実装レベルで抽出する。コード重複や見た目だけの共有は認めない |
| 配置 | `apps/web` を追加し、既存CEP（`src/`）の大規模な移動は行わない。既存ビルド・リリース経路・ユーザーデータ互換性を維持する |
| ホスティング | Cloudflare Workers + Static Assets。当面は無料枠と `workers.dev` を使用し、独自ドメインは購入しない |
| 将来候補 | Void は将来的な統合候補とし、今回の必須依存にしない |
| Server境界 | Web固有のServer Functionsと、CEP・将来の第三者クライアントが利用する公開APIを分離する |

公開ページはSEOとPrerenderを考慮し、将来の動的機能へ拡張可能な構造にする。初期対象は製品紹介、機能紹介、実際のスクリーンショット・デモ、ダウンロード、ドキュメント、更新情報、サポート導線とする。

## R0〜R5ロードマップとの関係

本サイトの初期版はR0の公開基盤（配布・ドキュメント・更新・サポート導線）を支える。R1（Online Catalog）以降でサイトへ動的機能を追加する場合は、[ロードマップ](../architecture/roadmap.md) の各フェーズIssueで範囲を確定する。初期版へR1以降の機能を混入させない。

## Rejected / 留保

- **旧Notion / Supabase実装の復活**: 権利・認証・配信方針と照合せずに復活させない。必要になった時点で新しいbackend契約として設計する。
- **独自ドメインの先行取得**: 無料枠と `workers.dev` で開始し、ドメインは必要性が確認されてから判断する。通知feedの既定URL（`ty-plus.app`）の扱いは #11 の配信先確定判断と連動させ、サイト構築だけで変更しない。
- **別リポジトリ化**: モノレポとし、デザインシステム・ドメインロジック・リリース運用を共有する。

## Amendment 余地

Void統合、独自ドメイン、R1以降のオンライン機能追加は、各判断時点の権利・コスト・セキュリティ条件で再評価する。本ADRはそれらを禁止せず、現時点の必須依存から外すことだけを決める。
