# Project Charter（無料OSS方針）

- Status: Accepted（R0設計の履歴正本。初回Stable `v0.10.1`は2026-11-12公開済み）
- Date: 2026-11-11
- 正本: `rebuildup/ty-plus#218`（R0計画）/ `rebuildup/ty-plus#220`（本charterの元Issue）/ `rebuildup/ty-plus#230`（移行の暫定正本）

## 目的

ty-plus を、誰でも無料で導入・利用できる public beta として提供する。配布・更新・通知は無料運用を前提とし、ログイン・コンテンツ投稿・課金を利用の前提にしない。

## 製品原則

1. **無料**: 導入・利用・更新に料金を要求しない。無料ライセンス認証を必要としない。
2. **アカウント不要のオフライン動作**: ローカルの主要機能（保存 / 復元を含む）はオフラインで動作し、アカウント登録を要求しない。オンライン機能の不達・破損がオフライン機能を妨げない。
3. **第三者が導入できる**: 説明書だけで Windows / macOS の After Effects に導入できる。開発者の個人環境に依存する手順を含まない。
4. **インフラ独立**: 配布・更新・通知の公式経路は無料枠で運用でき、特定の運営アカウント・契約に依存しない。上限・監視・停止条件を文書化する（#11）。
5. **将来の拡張との区別**: 後付けの有料化と将来のセルフホスト提供は、R0 の範囲外であり、本charterでは位置づけのみを残す。R0 の実装はこの拡張を妨げない設計にするが、R0 で設計・実装しきらない。

## R0 のユーザーフロー

```text
インストール → After Effects 起動 → ローカル機能の利用
           → 通知の確認 → 更新先へ安全に移動
```

- 不具合報告の入口がわかること（#9）。
- 更新・通知の確認はオフライン機能の前提条件にしない。

## R0 の非目標

- アカウント登録、利用者によるコンテンツ投稿
- 有料販売、強制自動更新
- 公開APIの独自SDK、セルフホスト用管理画面
- 全面UXP移行

## 資産の採用境界

- オフラインのコア機能とユーザー資産の保存/復元を最優先で保護する。
- 旧実装からの移植は `docs/migration/porting-ledger.md` の台帳に従い、権利監査（#2）を通過した資産に限定する。
- Log!N運営に依存するクラウド機能（preset catalog、licensing、通知/更新の旧実装）は、権利監査と本charterに基づく採用判断が確定するまで移植しない。R0 では代替として、公式の更新/通知feed（#7 / #8）を無料インフラ上に新設する。
- 配布APIの将来方針は ty-plus 専用のAPI前提にしない（第三者配布への拡張を妨げない）。

初回Stable `v0.10.1` は2026-11-12にGitHub Releasesで公開済み（公開リポジトリ）。既存のR0計画 `rebuildup/ty-plus#218` の期日は当初の計画値として残す。公開済みZXPの実機E2E検証は [本repo #10](https://github.com/ido-bata/ty-plus/issues/10) で継続し、今後の新しいリリースも本人の公開承認を必要とする。
