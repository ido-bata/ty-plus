# Loop ウィジェットは「1 サイクルの形状テンプレート + 周期パラメータ」で表現する

**状態:** Active

## 背景

旧 loop モードは「区間内で 1 回の ease を N 回繰り返す」だけの実装で、
振幅・減衰・進行方向・周期配分を操作できなかった。グラフも 1 サイクル分しか
描かず、出来上がる波形が想像しにくい。

## 決定

1. Loop の状態は **テンプレート点列 + cycles / amplitude / damping / bias / mode** で表す。
2. 複製規則は `docs/architecture/widget/loop.md` に 1 箇所だけ正本化し、
   React 側（描画）とホスト側（適用）が同じ式を使う。
3. 複製時はハンドル **x と y の両方**を `1 / cycles` にスケールする。
   x だけをスケールすると傾き比が変わり形状が歪む（既存ホスト実装のバグ）。

## 影響

- Easing ウィジェットとは Mode を共有しない。共有するのは描画・操作の基盤だけ。
- ホストの `applyLoopEasing` は複製規則の変更を Companion として更新する。
- 旧 loop モードの挙動は `cycle / amplitude=1 / damping=1 / bias=0` に包含される。
- 共有するのは周期モデル（`cyclic-wave.ts`）・座標処理・描画プリミティブであり、
  画面レイアウトと編集体験は Loop 側で持つ
