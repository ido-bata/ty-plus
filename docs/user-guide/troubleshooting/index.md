## Window > Extensions に ty-plus が出ない

After Effects を再起動してください。出ない場合は、ZXP Installer でインストールが完了しているか、システム側とユーザー側の両方を確認します。

```text
/Library/Application Support/Adobe/CEP/extensions
~/Library/Application Support/Adobe/CEP/extensions
```

## パネルが白画面または黒画面になる

拡張フォルダ内に `panel/index.html` と `assets/js/panel.entry.cjs` があるか確認します。開発用 symlink が残っている場合、古い `dist/cep-dev` を読んでいることがあります。

検証時に見つかった原因:

- `panel/index.html` が存在せず `ERR_FILE_NOT_FOUND` になった
- `CSInterface.js` の相対パスが間違っていた
- CommonJS エントリを通常 script として読み込み `exports is not defined` になった

## インストールが失敗する

未署名の `.zxp` は ZXP Installer / ExManCmd で失敗することがあります。署名済みの `.zxp` を使ってください。

## オンラインプリセットが表示されない

ネットワーク設定を確認します。社内プロキシや VPN を使っている場合は、接続先がブロックされていないか確認してください。

## Windows から移行したあとパスが合わない

オンボーディングまたは設定で、Presets、Scripts、Plug-ins のパスを macOS の実在フォルダに選び直します。

## パネルが表示されない

確認すること:

- After Effects を再起動する。
- `Window > Extensions` に ty-plus が表示されているか確認する。
- 開発版では `bun run host:deploy` を実行してから AE を起動する。
- CEP のデバッグ設定や拡張署名設定が配布形態に合っているか確認する。

## パネルが空白になる

確認すること:

- サポートルートに書き込み権限がある。
- 設定ファイルが壊れていない。
- 開発版では `bun run build` が成功している。
- AE のバージョンと CEP ランタイムで、使用している Chromium 機能が利用できる。

復旧手順:

1. After Effects を終了します。
2. サポートルートを退避します。
3. ty-plus を再起動します。
4. 初回設定をやり直します。
5. 退避したプリセットカタログやレイアウトを 1 つずつ戻します。

## プリセットが実行されない

確認すること:

- 対象レイヤー、コンポジション、プロジェクトが AE 側で選択されている。
- ファイルパスが存在する。
- `.ffx` は適用できるレイヤー種別を選択している。
- スクリプトは AE のセキュリティ設定と実行権限を満たしている。
- エラー表示、デバッグコンソール、AE の警告を確認する。

## フォントが表示されない

確認すること:

- AE の `app.fonts` から取得できるか。
- Chromium の Local Font Access API が使える環境か。
- `システムの全フォントを読み込む` をユーザー操作として押したか。
- document.fonts だけのフォールバック表示になっていないか。

## 設定が保存されない

確認すること:

- サポートルートが削除、移動、読み取り専用になっていない。
- パス変更後に確認ダイアログを承認したか。
- ネットワークドライブや同期フォルダで書き込み遅延が起きていないか。
- 複数 AE インスタンスで同時に同じサポートルートを書き換えていないか。

## オンライン機能が動かない

確認すること:

- ビルド時に Supabase URL、API base、公開キーが設定されている。
- 会社ネットワーク、プロキシ、ファイアウォールで通信が止まっていない。
- オフライン時の表示が、空白ではなく利用不可状態として表示される。
- ライセンスやクラウドプリセットの機能制限が意図通りか確認する。

## サポートに渡す情報

- ty-plus のバージョン。
- After Effects のバージョン。
- OS と言語。
- 再現手順。
- サポートルートの場所。
- 実行したプリセット種別とファイル拡張子。
- 表示されたエラー文。
- 可能であれば、操作前後のスクリーンショット。
