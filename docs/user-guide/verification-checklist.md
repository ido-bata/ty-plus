# 販売品質検証チェックリスト

この文書は、ty-plus を After Effects 用 CEP 製品として販売する前に、実 AE 上で「見落とすとサポート負債になる機能、状態、入力、環境、組み合わせ」を潰すための検証項目である。ブラウザ単体、unit test、mock CSInterface の成功は補助証跡にすぎない。最終判定は実 After Effects 上の CEP パネルで行う。

## 使い方

各チェックは 1 行 1 証跡で管理する。実施時は、最低でも次を記録する。

| 記録項目 | 内容 |
| --- | --- |
| Build | バージョン、commit、配布形態、署名有無 |
| Host | After Effects バージョン、CEP/CSXS、OS、表示倍率、言語 |
| Project | AE プロジェクト種別、保存状態、選択状態、素材状態 |
| Data | サポートルート、プリセットルート、対象ファイル、設定 JSON |
| Result | 未実施 / 合格 / 不合格 / 保留 / 対象外 |
| Evidence | スクリーンショット、動画、ログ、最小 AEP、再現手順 |
| Support note | ユーザーから問い合わせが来た場合の回答文、回避策、既知制限 |

## 合格基準

- ユーザーが普通に触る導線だけでなく、壊れた設定、欠落ファイル、権限不足、ネットワーク断、AE 側の未選択状態でも、空白パネル、無反応、データ破損、復旧不能にならない。
- 失敗時は、何が必要かをユーザーが判断できる表示またはログが残る。
- AE 再起動、パネル再読み込み、サポートルート移動後も、状態が仕様通りに復元される。
- 既存ユーザーのデータを更新しても、ワークスペース、プリセット、設定が意図せず消えない。
- 不合格項目は、販売前に修正、既知制限、ドキュメント化、販売スコープ外のいずれかに分類されている。
