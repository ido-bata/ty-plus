# v0.11.0 実機ビジュアルレビュー手順（#166 人間受入用）

対象ビルド: `v0.11.0-insider.9`（GitHub Release の macOS ZIP）または Stable 候補 `0.11.0`。
Storybook capture（429/429 ok）は機械的健全性の証拠であり、**審美・操作感の合格はこの実機レビューで判断する**。

## 準備

1. `https://github.com/ido-bata/ty-plus/releases/tag/v0.11.0-insider.9` から `ty-plus-v0.11.0-insider.9-macos.zip` を DL・展開し、`app.ty-plus` として `~/Library/Application Support/Adobe/CEP/extensions/` に配置（既存があれば退避）。
2. AE 2027 を起動し、ウィンドウ → エクステンション → ty-plus でパネルを開く。
3. 日本語 UI 前提。各項目で「崩れ・重なり・見切れ・コントラスト不足・状態の不整合」がないかを確認する。

## レビュー優先順（所要 20–30 分）

### 1. Directory Browser（最重要・面積最大）

- [ ] グリッド表示: タイルの整列、サムネイル欠落時のプレースホルダ、長いファイル名の truncate
- [ ] リスト表示への切替: 列幅、アイコン、選択ハイライト
- [ ] 検索フィールド: 入力時のハイライト、0件時の empty 表示、クリア操作
- [ ] パスバー: 深い階層での省略表示、go-up ボタンの disabled 状態
- [ ] ドラッグ選択・複数選択時のサマリ表示

### 2. 検索・クイックアクション

- [ ] コマンドパレット/クイックアクション: 検索中の絞り込み表示、0件、キーボードフォーカスリング
- [ ] 検索結果ハイライトが本文と区別できること

### 3. Preset / Group

- [ ] Preset カタログ: グループ見出し、タイルの hover/selected 状態
- [ ] Preset 追加ダイアログ: 入力欄のフォーカス、バリデーションエラー表示、footer ボタンの disabled
- [ ] Preset エディタ: Markdown 表示、長文スクロール、プレースホルダ

### 4. Workspace

- [ ] パネル内 widget の配置・リサイズ: スナップ時のガイド、他 widget との重なり
- [ ] スナップショット: 保存→ステータスバーのドロップダウン→復元の一連操作
- [ ] ウィジェット追加/削除時のレイアウト再構成

### 5. Settings ダイアログ

- [ ] 各セクションのナビゲーション、選択状態の表示
- [ ] 更新セクション: チャンネル選択、更新状態の表示（今回の insider.9 では「最新です」になるはず）
- [ ] トークンエディタ: 色プレビュー、入力中の表示

### 6. 状態系（余力があれば）

- [ ] 通知センター: 未読/既読、詳細パネルの loading
- [ ] オンボーディング/empty 状態: DirectoryBrowserOnboarding 相当の実機表示
- [ ] エラー状態: 意図的に発生させられる範囲で error 表示の視認性

## 判定の記録

- 全項目 PASS なら #166 を close し、PR #188 の受入材料とする。
- pixel diff / reg-suit 等の自動視覚回帰は**不採用**（`storybook-visual-review-0-11-0.md` に理由記録済み）。本手順が最終ゲート。
